🚀 Quick Start

Selecione uma ferramenta no menu lateral para começar. Cada ferramenta tem instruções específicas abaixo.

❓ Perguntas Frequentes

🎵 Converter Áudio +

Converte arquivos de áudio entre formatos (MP3, WAV, FLAC, AAC).

  • Selecione uma pasta ou arquivo único
  • Escolha o formato de saída
  • Clique em Converter
🖼️ Converter Imagem +

Converte imagens entre formatos (HEIC/HEIF, PNG, JPG, WEBP, BMP, ICO).

  • Selecione pasta ou arquivo
  • Escolha o formato de saída
  • Clique em Converter
📸 Comprimir Imagem +

Comprime imagens JPEG/PNG para reduzir tamanho mantendo qualidade.

  • Selecione pasta com imagens
  • Imagens comprimidas ficam em pasta "comprimidas"
🎬 Comprimir Vídeo +

Comprime vídeos usando FFmpeg. Suporta CPU ou GPU (mais rápido).

  • Selecione vídeos para comprimir
  • Escolha CPU ou GPU
  • Vídeos comprimidos em pasta "comprimidos"
🌐 Favicon Generator +

Gera favicons e manifest para sites.

  • Selecione uma imagem
  • Defina nome do site e cor
  • Gerado automáticamente
🔄 Video Converter +

Converte vídeos entre formatos ou cria GIF.

  • Selecione vídeos
  • Escolha formato de saída (MP4, AVI, MKV, GIF, etc)
📥 Video Downloader +

Baixa vídeos do YouTube e outros sites.

  • Cole a URL do vídeo
  • Clique em Verificar
  • Escolha pasta e baixe
🕷️ Web Scraper +

Baixa imagens/vídeos de sites. Suporta regras .md (Cérebro).

  • Digite a URL do site
  • Analise para ver o que tem
  • Baixe o que precisar
  • Use Cérebro para renomear arquivos
📝 Transcrever Áudio +

Transcreve áudio usando Whisper AI.

  • Selecione arquivos de áudio
  • Escolha modelo (Small rápido, Medium preciso)
  • Selecione idioma ou auto-detectar
✂️ Remover Fundo +

Remove fundo de imagens usando IA.

  • Selecione imagens
  • Fundo removido automaticamente
  • Salvo em pasta "sem_fundo"
🗂️ Organizador Imagens +

Organiza imagens por data de criação.

  • Selecione pasta com imagens
  • Organizado por ano/mês
🎥 Logger Pro +

Organiza vídeos por metadados (data, duração).

  • Selecione pasta com vídeos
  • Cria CSV com informações
☁️ GDrive Dumper +

Baixa pastas inteiras do Google Drive.

  • Cole o link da pasta
  • Selecione destino
  • Baixe tudo
